---

## 🎯 Target Audience & Core Pitch
- **Audience:** D2C apparel brands, boutique fashion creators, export houses, and thrifting curators.
- **Core Pitch:** *"Sell on DupeScout — Put Your Catalog in Front of 500k+ Gen Z Shoppers Searching for Affordable Dupes."*
- **Key Value Props:**
  1. **Multimodal Demand Funnel:** Shoppers upload screenshots of ₹15,000+ luxury designer wear; our visual AI matches them directly to merchant catalogs.
  2. **Automated AI Catalog Vectorization:** Bulk lookbook image upload auto-generates cuts, fabrics, colors, and aesthetic tags.
  3. **Trending Dupe Radar:** Live merchant analytics on trending luxury searches with unmet supply.
  4. **Zero-Risk Onboarding:** 0% commission for first 90 days, daily automated UPI payouts, Shiprocket & Delhivery 1-click labels.

---

## 🛡️ Dual-Boundary Architecture Notice
This repository is the public static showcase satellite. All proprietary Python FastAPI vector search engines, PostgreSQL `pgvector` databases, and CLIP vision models remain strictly secured inside the private parent monorepo: `Trend-Tribe/DupeScout`.
